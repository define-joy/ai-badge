# Skills

Reusable AI-agent workflows for DefineJoy AI Badge. Each skill is a subdirectory with `SKILL.md` (YAML `name` + trigger `description`). Add a paired `SKILL.zh_CN.md` when the skill has user-facing steps.

## Current skills

| Skill | What it does |
| --- | --- |
| add-play | Create a new user app under `apps/` registered with `BADGE_APP`. |
| extend-hardware | Add a Port, Adapter, and Facade method without changing Runtime. |
| validate-framework | Run host tests and report Build / Host / Device / Unverified separately. |
| issue-suggestions | After a release, draft GitHub issues for DefineJoy AI Badge (review before submit). |
| experience-pr | After a release, capture durable learnings as a documentation PR (review before submit). |
