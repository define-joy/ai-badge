# Skills

DefineJoy AI Badge 的可复用 AI 工作流。每个 skill 独立子目录，至少包含带 YAML `name` 与触发 `description` 的 `SKILL.md`。面向操作者的步骤配 `SKILL.zh_CN.md`。

## 当前 skills

| Skill | 作用 |
| --- | --- |
| add-play | 在 `apps/` 新建玩法并用 `BADGE_APP` 注册 |
| extend-hardware | 新增 Port + Adapter + 外观方法，不改 Runtime |
| validate-framework | 跑 host 测试，分开报告 Build / Host / Device / Unverified |
| issue-suggestions | 发布后整理改进点，起草 GitHub issue（先审后提） |
| experience-pr | 发布后沉淀可复用经验为文档 PR（先审后提） |
